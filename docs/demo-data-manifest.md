# Demo data manifest

- 30 school rows total: 6 public directory school names/UDISE identifiers and 24 synthetic school rows.
- 440 learner profiles: synthetic. Names, grades, attendance, scores and intervention records are invented demonstration data.
- 1,600 assessment observations: synthetic baseline/midline.
- 61 competency activity plans: locally curated teacher-use plans. Each points to the official DIKSHA FLN discovery page; these are not represented as live DIKSHA catalogue records.
- Four block labels: Visrakh, Dadri, Dankaur, Jewar, based on the district directory.

Public directory reference: https://in.knowyourschools.com/directory/uttar-pradesh/gautam-buddha-nagar
Official DIKSHA FLN discovery: https://diksha.gov.in/fln.html

The school directory reference is metadata only. Do not infer learner counts or learning outcomes for any named school from this synthetic database.
